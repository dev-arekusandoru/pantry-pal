# Ingredient sticker book

The **Sticker book** at `/dex` collects one sticker for each ingredient in the household's recipe catalog that you have cooked with.

The screen groups ingredients by aisle. Collected stickers show when you first cooked the ingredient and how many completed cooks used it. Select a sticker to see its recipes. Uncollected ingredients appear as faint icons; their names remain available to screen readers.

The count and progress bar show collected ingredients against the catalog. The book uses completed cook history, so planned meals do not collect stickers. Ingredients added to the household appear as new empty stickers.
